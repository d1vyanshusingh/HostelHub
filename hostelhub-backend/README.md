# HostelHub - Spring Boot 3 Backend REST API

Production-ready backend REST API for **HostelHub (Smart Hostel Management System)**, built with **Java 17+**, **Spring Boot 3.2.x**, **Spring Data JPA**, **Hibernate**, **Spring Security 6 with JWT**, and **MySQL**.

---

## 🏗️ Architecture Overview

The backend follows the enterprise 3-tier architecture:

```
[ HTTP Client / React Frontend (http://localhost:5173) ]
                       │
                       ▼
         [ Security Filter & CORS ]
                       │ (JwtAuthenticationFilter)
                       ▼
          [ Controller Layer ] (DTOs in / DTOs out)
                       │
                       ▼
            [ Service Layer ] (Business Logic & Transactions)
                       │
                       ▼
          [ Repository Layer ] (Spring Data JPA / Hibernate)
                       │
                       ▼
              [ MySQL Database ] (hostelhub_db)
```

---

## 🚀 Quick Start Guide

### 1. Database Setup
Create the MySQL database (or configure your credentials in `src/main/resources/application.properties`):

```sql
CREATE DATABASE IF NOT EXISTS hostelhub_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Default credentials in `application.properties`:
- **URL**: `jdbc:mysql://localhost:3306/hostelhub_db?createDatabaseIfNotExist=true`
- **Username**: `root`
- **Password**: `root`

### 2. Build and Run
```bash
# Using Maven
mvn clean spring-boot:run
```

The application starts on `http://localhost:8080`.

## 📡 REST API Reference

### 1. Authentication (`/api/auth`)

#### `POST /api/auth/register`
Create a new user account.
```json
{
  "email": "new.student@hostelhub.edu",
  "password": "password123",
  "name": "Jane Doe",
  "regNo": "RA211100301199",
  "role": "STUDENT"
}
```

#### `POST /api/auth/login`
Authenticate and obtain a JWT token.
```json
{
  "email": "alex.doe@hostelhub.edu",
  "password": "password123"
}
```
**Response:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "tokenType": "Bearer",
  "id": 1,
  "email": "alex.doe@hostelhub.edu",
  "name": "Alex Doe",
  "regNo": "RA211100301089",
  "role": "STUDENT"
}
```

---

### 2. Complaints (`/api/complaints`)

*Include header: `Authorization: Bearer <JWT_TOKEN>`*

#### `POST /api/complaints` *(Role: STUDENT, ADMIN)*
Submit a new maintenance ticket.
```json
{
  "category": "Electrical",
  "description": "Room ceiling fan making rattling noise on speed 3",
  "priority": "Medium"
}
```

#### `GET /api/complaints/my-complaints` *(Authenticated)*
Fetch tickets raised only by the authenticated student.

#### `GET /api/complaints/all` *(Role: WARDEN, ADMIN)*
Fetch all complaints across all hostel blocks.

#### `PUT /api/complaints/{id}/status` *(Role: WARDEN, ADMIN)*
Update complaint status (e.g. to `RESOLVED` or `IN_PROGRESS`).
```json
{
  "status": "RESOLVED"
}
```

### 3. Rooms (`/api/rooms`)

```json
    "roomNumber": "A-204",
    "capacity": 3,
    "currentOccupancy": 2,
    "availableBeds": 1,
    "isAvailable": true
  }
]
```
